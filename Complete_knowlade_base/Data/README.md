# iStore Hub RAG Beginner Dataset

This is a fictional dataset for learning NLP and Retrieval-Augmented Generation.

Suggested progression:
1. Load all .txt files.
2. Split documents into paragraphs/chunks.
3. Tokenize with NLTK.
4. Remove stopwords and punctuation.
5. Implement keyword-overlap retrieval.
6. Retrieve top 3 relevant chunks.
7. Build a prompt containing the question + retrieved context.
8. Send that prompt to your chosen LLM.
9. Later replace keyword retrieval with TF-IDF/BM25.
10. Finally experiment with embeddings and a vector database.

Important:
The company, policies, products, prices and contact details are fictional.
Do not treat them as official Apple policies or current Apple pricing.
